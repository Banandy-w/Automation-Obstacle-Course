# Goals
* Practice automation by running through challenges found here https://obstaclecourse.tricentis.com/Obstacles/List
* Do NOT implement a Page Object Model so you can further familiarize yourself with selenium or whatever framework used.

# Dependencies
* Selenium
* Python 3.12.3

# How to Run
* python \path_to\Tricentis-Challenges.py browser -speed
* Replace browser with: 'firefox', 'edge', 'chrome', or 'safari'
* Replace -speed with:
  - '-m' or '-manual' to have a command line input 'automate' per test before the script automates the test, allowing you to attempt the obstacle course by hand.
  - '-a' or '-auto' to run through the tests via automation
